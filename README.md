# 筆記問題解答スペース

筆記問題解答
問４　（int a;とextern int a;の違いを述べなさい。）
int a;はint型の変数aを宣言し使うメモリを確保する
extern int a;は他で宣言されている変数を参照するためのもの？宣言時ではメモリの確保はしない

問５　（二重定義エラーとはどのような状況で起こるか答えなさい。）
名前と型が同じ変数、関数がある時のエラー、型が違えばオーバーロードとなりエラーにならない

問６　（ビルドとは大きく２つのステップに分けることができます。２つの実行される順番に答えなさい。）
コンパイル、リンク

問７　（文字列リテラルは何を返しますか？）
文字列の先頭アドレス

問８　（文字列の配列を作成する際、2つの方法があります。その２つの方の違いと、どちらが定石が説明しなさい。）
文字を一つずつ配列にいれ最後に\0を自分で配列に入れる必要があるパターン
文字をまとめて入れ\0は自動でやってくれる文字列リテラルを使うパターン
後者の文字列リテラルうぃ使うパターンが一般的
